# Enterprise DevSecOps Portfolio

A Streamlit-based engineering portfolio showcasing DevSecOps, platform engineering, CI/CD automation, cloud infrastructure, and enterprise remediation orchestration concepts.

## About

This project is a professional portfolio application built to present enterprise engineering capabilities in a structured, dashboard-style format.

It highlights experience across:

- DevSecOps
- Platform Engineering
- CI/CD Automation
- Cloud Automation
- Infrastructure Automation
- Vulnerability Remediation
- Enterprise Governance
- Automation Engineering

## Tech Stack

- Python
- Streamlit
- Graphviz
- Custom CSS

## Run Locally

```bash
pip install streamlit
streamlit run app.py
